# APEX-GraphMoE

This repository contains the implementation and data organization for APEX-GraphMoE.

## Modules

- `LLN/`: LLM-enhanced LightGCN network used to construct semantic user-user relations from user interest summaries.

Large trained checkpoints are not committed directly because they exceed normal GitHub repository size limits. See the README files under `LLN/models/` and `LLN/outputs/` for artifact descriptions and expected local paths.
