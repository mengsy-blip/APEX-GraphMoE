# LLN

LLN builds semantic user-user relations from LLM-generated user interest summaries and trains a LightGCN model on interaction data enhanced by those semantic relations.

## Directory layout

- `data/pre_finetuning_user_portraits/`: user interest summaries generated before LoRA fine-tuning.
- `data/lora_generated_user_portraits/`: user interest summaries generated by the LoRA-adapted model.
- `data/gcn_inputs/`: BERT-converted user-interest data used as the input for LLN/LightGCN training.
- `src/finetune_deepseek_lora.py`: DeepSeek LoRA fine-tuning script.
- `src/lln_lightgcn_train.py`: LLN training script based on LightGCN and BERT user-interest embeddings.
- `models/lora_model/`: placeholder for the trained LoRA adapter.
- `outputs/gcn_logs_incremental_bert/`: split archive of trained LLN/LightGCN graph outputs for MMOE training.

## Data format

The user portrait CSV files use the following core fields:

- `user_id`
- `user_interest_summary`
- `scene`
- extra generation metadata such as `generation_method`, `data_quality`, and `gpu_rank`

The `data/gcn_inputs/` directory contains the BERT-converted inputs for GCN training:

- `scene_*_ddp_lora_portraits.csv`: LoRA-generated user interest summaries by scene.
- `interest_embeddings/scene_*_interest_embeddings.zip`: compressed BERT interest embeddings by scene. Unzip these files before using them as embedding inputs.
- `interest_embeddings/processing_report.json`: conversion summary.

## Usage

Install dependencies:

```bash
pip install -r LLN/requirements.txt
```

Fine-tune the LLM:

```bash
torchrun --nproc_per_node=2 LLN/src/finetune_deepseek_lora.py \
  --model_name deepseek-ai/deepseek-llm-7b-chat \
  --training_data LLN/data/training_data/all_scenes_training.json \
  --output_dir LLN/models/lora_model
```

Train LLN:

```bash
python LLN/src/lln_lightgcn_train.py \
  --h5_files /path/to/antm2c_10m_part0_train_embeddings.h5 /path/to/antm2c_10m_part1_train_embeddings.h5 /path/to/antm2c_10m_part2_train_embeddings.h5 \
  --bert_embeddings_dir /path/to/bert_user_embeddings \
  --save_dir LLN/outputs/gcn_logs_incremental_bert \
  --device_id 0
```

The BERT embedding directory is expected to contain files named `scene_{scene_id}_embeddings.pkl`.
